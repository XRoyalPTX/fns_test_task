## Откуда данные (все источники — официальные)

1. **ЕМИСС, показатель 42549** — «Задолженность по налогам и сборам, пеням и налоговым санкциям»,
   ответственный орган — ФНС России: https://www.fedstat.ru/indicator/42549
   (ежемесячные данные, разрезы: виды платежей, уровни бюджета, физлица, регионы).
   Использованы срезы «январь» 2018–2022 гг. как сопоставимые между годами.
2. **ФНС, формы статистической налоговой отчётности**: https://www.nalog.gov.ru/rn77/related_activities/statistics_and_analytics/forms/ — форма №4-НМ (задолженность) и №1-НМ (начисление/поступление).
3. **Открытые данные ФНС**: набор `7707329152-poved` (форма №1-НМ, CSV) — https://www.nalog.gov.ru/opendata/7707329152-poved/ ; набор `7707329152-debtam` (задолженность по субъектам) — https://www.nalog.gov.ru/opendata/7707329152-debtam/ .

Все файлы скачаны только с официальных доменов `nalog.gov.ru`, `nalog.ru`, `fedstat.ru`.

## Ключевые выводы анализа

- 2018–2021 — устойчивое снижение совокупной задолженности: 1 169,9 → 809,1 млрд руб. (−31%).
- 2022 — аномальный рост на 36% (до 1 103,2 млрд руб.), сформированный федеральными платежами
  крупных компаний: НДС +43%, налог на прибыль +103%, НДПИ +167% (споры/авансы, санкционный шок ликвидности).
- Структура стабильна: недоимка ~78–79%, пени и санкции ~21–22%.
- Долг физлиц (~216–220 млрд руб.) не снижается; более половины — транспортный налог.
- Топ-10 субъектов РФ концентрируют ~60% задолженности (Москва — около трети).
